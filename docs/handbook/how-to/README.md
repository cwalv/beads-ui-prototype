# How-to

Task-oriented recipes. Each assumes you already know the concepts and
just want the "how do I do X" answer.

## Contents

| How-to | Solves |
|---|---|
| [create-from-markdown.md](create-from-markdown.md) | Create one or many beads from a markdown file. |
| [create-a-graph.md](create-a-graph.md) | Create a bead DAG atomically via `bd create --graph`. |
| [write-a-lifecycle-hook.md](write-a-lifecycle-hook.md) | Wire an `on_create` / `on_update` / `on_close` script. |
| [write-a-formula.md](write-a-formula.md) | Author a formula with vars, conditions, loops, gates. |
| [add-a-gate.md](add-a-gate.md) | Block work on a GitHub run, PR, timer, or human decision. |
| [push-to-github.md](push-to-github.md) | Sync beads ↔ GitHub Issues. |
| [back-up-and-restore.md](back-up-and-restore.md) | Export to JSONL; use Dolt backup; restore. |

## When to use a how-to vs a tutorial

Tutorials teach concepts via walkthroughs. How-tos assume you know the
concepts and just need the recipe. If the first two paragraphs here
don't make sense, start with [tutorials/](../tutorials/README.md).
